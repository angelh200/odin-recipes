# Odin Recipes

## Description
Website project with lists and links to few recipes.
Each recipe has it's own page and includes and image of the finished dish, a description, a list of ingredients, and the steps.

At the time this website is pure HTML.

## Skills
Skills learned:
* Setting up a basic HTML boilerplate.
* Structure with proper HTML tags (heading, paragraphs).
* Creating lists.
* Adding images using relative and absolute paths.
* Using Git commands.
